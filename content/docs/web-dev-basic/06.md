## 📖 Materi

### Apa Itu JavaScript?

JavaScript (JS) adalah bahasa pemrograman yang membuat halaman web menjadi **interaktif dan dinamis**. Jika HTML adalah rangka dan CSS adalah dekorasi, JavaScript adalah "nyawa" yang membuat website bisa merespons aksi pengguna.

Contoh hal yang bisa dilakukan JavaScript:
- Membuka/menutup menu navigasi (hamburger menu)
- Menampilkan/menyembunyikan konten
- Memvalidasi form sebelum dikirim
- Menampilkan animasi dan efek
- Mengambil data dari server (tanpa reload halaman)

---

### Cara Menyertakan JavaScript

```html
<!-- 1. Internal JS (di dalam HTML) — untuk testing singkat -->
<script>
    console.log("Halo dari JavaScript!");
</script>

<!-- 2. External JS (file terpisah) — DIREKOMENDASIKAN -->
<!-- Letakkan di BAWAH </body> agar HTML dimuat dulu sebelum JS dijalankan -->
<script src="script.js"></script>
```

```javascript
// Di dalam script.js
console.log("Halo dari file JS eksternal!");
```

> 💡 **Tips:** Letakkan tag `<script>` di akhir `<body>` (sebelum `</body>`) agar HTML sudah termuat sebelum JavaScript mencoba memanipulasinya.

### Variabel

Variabel adalah tempat untuk menyimpan data. JavaScript modern menggunakan `let` dan `const`.

```javascript
// const — nilai TIDAK bisa diubah (direkomendasikan sebagai default)
const namaSaya = "Budi Santoso";
const umur = 20;
const piValue = 3.14;

// let — nilai BISA diubah
let skor = 0;
let pesanSapaan = "Halo!";

skor = 100;        // OK, let bisa diubah
pesanSapaan = "Selamat datang!";  // OK

// var — cara lama, hindari penggunaan var
var namaLama = "Hindari var";  // kurang direkomendasikan
```

Aturan penamaan variabel:
- Dimulai dengan huruf, `_`, atau `$` (tidak boleh dengan angka)
- Gunakan **camelCase**: `namaPengguna`, `totalHarga`
- Deskriptif dan bermakna: `nilaiUjian` lebih baik dari `n`

### Tipe Data

```javascript
// String (teks)
const nama = "Budi";
const kota = 'Medan';
const pesan = `Halo, nama saya ${nama}`; // template literal

// Number (angka)
const usia = 20;
const tinggi = 175.5;
const minus = -10;

// Boolean (benar/salah)
const sudahLogin = true;
const isAdmin = false;

// Null (tidak ada nilai, disengaja)
const dataPengguna = null;

// Undefined (belum ada nilai)
let dataBaru;
console.log(dataBaru); // undefined

// Array (daftar)
const buah = ["apel", "mangga", "jeruk"];
console.log(buah[0]); // "apel" (index dimulai dari 0)
console.log(buah.length); // 3

// Object (kumpulan data)
const mahasiswa = {
    nama: "Budi",
    usia: 20,
    kota: "Medan",
    aktif: true
};
console.log(mahasiswa.nama); // "Budi"
console.log(mahasiswa["kota"]); // "Medan"
```

### Operator

```javascript
// Aritmatika
let a = 10;
let b = 3;
console.log(a + b);  // 13
console.log(a - b);  // 7
console.log(a * b);  // 30
console.log(a / b);  // 3.333...
console.log(a % b);  // 1 (sisa bagi / modulus)
console.log(a ** b); // 1000 (10 pangkat 3)

// Perbandingan (hasilnya boolean)
console.log(5 == "5");   // true  (nilai sama, tipe diabaikan)
console.log(5 === "5");  // false (nilai DAN tipe harus sama — gunakan ini!)
console.log(5 !== 3);    // true
console.log(10 > 5);     // true
console.log(10 <= 10);   // true

// Logika
console.log(true && false); // false (AND)
console.log(true || false); // true  (OR)
console.log(!true);         // false (NOT)
```

### Kondisional (if/else)

```javascript
const nilai = 75;

if (nilai >= 90) {
    console.log("Grade A");
} else if (nilai >= 80) {
    console.log("Grade B");
} else if (nilai >= 70) {
    console.log("Grade C");
} else {
    console.log("Grade D");
}

// Ternary operator (if/else singkat)
const status = nilai >= 70 ? "Lulus" : "Tidak Lulus";
console.log(status); // "Lulus"
```

### Fungsi (Function)

```javascript
// Deklarasi fungsi
function sapa(nama) {
    return `Halo, ${nama}! Selamat datang.`;
}

// Memanggil fungsi
const pesan = sapa("Budi");
console.log(pesan); // "Halo, Budi! Selamat datang."

// Arrow Function (cara modern)
const tambah = (a, b) => a + b;
console.log(tambah(5, 3)); // 8

// Arrow Function dengan body
const perkenalan = (nama, usia) => {
    const teks = `Nama saya ${nama}, usia ${usia} tahun.`;
    return teks;
};

console.log(perkenalan("Budi", 20));
```

### DOM Manipulation

**DOM (Document Object Model)** adalah representasi struktur HTML sebagai objek JavaScript. Dengan DOM, kita bisa membaca dan mengubah konten, atribut, dan gaya elemen HTML.

#### Mengakses Elemen

```javascript
// Berdasarkan ID (mengembalikan satu elemen)
const judul = document.getElementById('judul-utama');

// Berdasarkan class (mengembalikan NodeList/koleksi)
const semuaTombol = document.querySelectorAll('.tombol');

// Berdasarkan selector CSS (mengembalikan elemen pertama yang cocok)
const navbar = document.querySelector('.navbar');
const inputNama = document.querySelector('input[name="nama"]');
```

#### Mengubah Konten

```javascript
const judul = document.getElementById('judul');

// Mengubah teks
judul.textContent = "Teks Baru";

// Mengubah HTML di dalam elemen
judul.innerHTML = "<span>Teks dengan <strong>HTML</strong></span>";

// Membaca teks
console.log(judul.textContent);
```

#### Mengubah Gaya (CSS)

```javascript
const kotak = document.querySelector('.kotak');

// Mengubah properti style langsung
kotak.style.backgroundColor = "blue";
kotak.style.fontSize = "20px";
kotak.style.display = "none";    // menyembunyikan elemen

// Menambah/menghapus class (LEBIH BAIK dari style langsung)
kotak.classList.add('aktif');
kotak.classList.remove('aktif');
kotak.classList.toggle('aktif'); // tambah jika tidak ada, hapus jika ada
kotak.classList.contains('aktif'); // true/false
```

#### Mengubah Atribut

```javascript
const gambar = document.querySelector('img');
const link = document.querySelector('a');

gambar.setAttribute('src', 'images/foto-baru.jpg');
gambar.setAttribute('alt', 'Foto baru');

link.setAttribute('href', 'https://github.com');
link.getAttribute('href'); // membaca atribut
```

### Event Handling

Event adalah kejadian yang terjadi di halaman — seperti klik tombol, mengisi input, atau menggulir halaman.

```javascript
// Mendengarkan event klik
const tombol = document.getElementById('tombolKlik');

tombol.addEventListener('click', function() {
    console.log("Tombol diklik!");
});

// Menggunakan arrow function
tombol.addEventListener('click', () => {
    alert("Halo dari tombol!");
});

// Event yang umum digunakan
elemen.addEventListener('click', handler);       // klik mouse
elemen.addEventListener('mouseover', handler);   // kursor masuk ke elemen
elemen.addEventListener('mouseout', handler);    // kursor keluar dari elemen
elemen.addEventListener('keydown', handler);     // tombol keyboard ditekan
elemen.addEventListener('submit', handler);      // form dikirim
elemen.addEventListener('input', handler);       // nilai input berubah
elemen.addEventListener('change', handler);      // nilai select/radio berubah
window.addEventListener('scroll', handler);      // halaman di-scroll
window.addEventListener('load', handler);        // halaman selesai dimuat
```

### JavaScript (script.js)

```javascript
// ===========================
// 1. HAMBURGER MENU
// ===========================
const hamburgerBtn = document.getElementById('hamburgerBtn');
const navbarMenu = document.getElementById('navbarMenu');

hamburgerBtn.addEventListener('click', () => {
    navbarMenu.classList.toggle('aktif');
    hamburgerBtn.classList.toggle('aktif');
});

// Tutup menu saat link diklik
const navLinks = document.querySelectorAll('.navbar-menu a');
navLinks.forEach(link => {
    link.addEventListener('click', () => {
        navbarMenu.classList.remove('aktif');
        hamburgerBtn.classList.remove('aktif');
    });
});


// ===========================
// 2. COUNTER INTERAKTIF
// ===========================
let nilaiCounter = 0;
const tampilCounter = document.getElementById('angkaCounter');
const btnTambah = document.getElementById('btnTambah');
const btnKurang = document.getElementById('btnKurang');
const btnReset = document.getElementById('btnReset');

function perbaruiCounter() {
    tampilCounter.textContent = nilaiCounter;
}

btnTambah.addEventListener('click', () => {
    nilaiCounter++;
    perbaruiCounter();
});

btnKurang.addEventListener('click', () => {
    nilaiCounter--;
    perbaruiCounter();
});

btnReset.addEventListener('click', () => {
    nilaiCounter = 0;
    perbaruiCounter();
});


// ===========================
// 3. SISTEM TAB DINAMIS
// ===========================
const tabBtns = document.querySelectorAll('.tab-btn');
const tabContents = document.querySelectorAll('.tab-content');

tabBtns.forEach(btn => {
    btn.addEventListener('click', () => {
        const targetId = btn.getAttribute('data-target');

        // Hapus class 'aktif' dari semua tab button dan content
        tabBtns.forEach(b => b.classList.remove('aktif'));
        tabContents.forEach(c => c.classList.remove('aktif'));

        // Tambahkan class 'aktif' ke yang diklik
        btn.classList.add('aktif');
        document.getElementById(targetId).classList.add('aktif');
    });
});


// ===========================
// 4. HIGHLIGHT NAVBAR SAAT SCROLL
// ===========================
const navbar = document.querySelector('.navbar');

window.addEventListener('scroll', () => {
    if (window.scrollY > 50) {
        navbar.style.boxShadow = '0 2px 20px rgba(0,0,0,0.3)';
    } else {
        navbar.style.boxShadow = 'none';
    }
});
```

## 📌 Ringkasan

- JavaScript menambahkan **interaktivitas** pada halaman web
- Gunakan `const` untuk nilai tetap, `let` untuk nilai yang bisa berubah
- **DOM** adalah antarmuka antara JavaScript dan elemen HTML
- Gunakan `document.querySelector()` dan `getElementById()` untuk mengakses elemen
- `addEventListener()` digunakan untuk menangani event seperti klik dan input
- `classList.toggle()` adalah cara mudah untuk menambah/menghapus class CSS
