## 📖 Materi

### Apa Itu Website?

Website adalah kumpulan halaman yang dapat diakses melalui internet menggunakan browser (seperti Chrome, Firefox, atau Edge). Setiap halaman website terdiri dari teks, gambar, video, dan elemen interaktif lainnya.

Analogi sederhana: bayangkan website seperti sebuah **majalah digital**. Majalah punya halaman-halaman berisi konten, desain, dan kadang ada bagian interaktif (seperti kupon). Website bekerja dengan cara yang sama.

Ada dua jenis website:

- **Website Statis** — kontennya tetap, tidak berubah secara otomatis. Cocok untuk portofolio, landing page, dan profil pribadi.
- **Website Dinamis** — kontennya bisa berubah sesuai data atau pengguna. Contoh: media sosial, e-commerce.

Kita akan belajar membuat **website statis** di modul ini.

---

### Cara Kerja Web (Request–Response)

Saat kamu mengetik alamat website di browser, terjadi proses berikut:

1. **Browser** mengirimkan permintaan (request) ke server
2. **Server** menerima permintaan dan mencari file yang diminta
3. **Server** mengirimkan file HTML, CSS, JS kembali ke browser (response)
4. **Browser** membaca dan menampilkan halaman

Analogi: seperti memesan makanan di restoran. Kamu (browser) memesan ke pelayan (internet), pelayan menyampaikan ke dapur (server), dapur memasak lalu mengirim makanan kembali (response).

```
Browser  ──── request ────►  Server
Browser  ◄─── response ────  Server
         (HTML, CSS, JS)
```

---

### Frontend vs Backend

| Aspek | Frontend | Backend |
|---|---|---|
| Definisi | Tampilan yang dilihat pengguna | Logika yang berjalan di server |
| Bahasa | HTML, CSS, JavaScript | Python, PHP, Node.js, dll |
| Contoh | Tombol, warna, layout | Database, login, transaksi |
| Analogi | Tampilan toko | Gudang & kasir di belakang |

Dalam modul ini, kita fokus pada **frontend** — yaitu semua yang terlihat dan dirasakan pengguna di browser.

---

### HTML, CSS, dan JavaScript

Ketiganya adalah fondasi web development. Setiap teknologi punya peran berbeda:

**HTML (HyperText Markup Language)**
Adalah kerangka atau struktur halaman web. Seperti **rangka rumah** — menentukan ada berapa kamar, di mana pintu, di mana jendela.

**CSS (Cascading Style Sheets)**
Adalah tampilan atau dekorasi halaman. Seperti **cat, wallpaper, dan furnitur** — membuat rumah terlihat indah dan nyaman.

**JavaScript**
Adalah perilaku atau interaktivitas halaman. Seperti **sistem listrik dan kunci pintu otomatis** — membuat rumah bisa "bergerak" dan merespons pengguna.

```
HTML  → Struktur   (apa yang ada)
CSS   → Tampilan   (seperti apa tampilannya)
JS    → Perilaku   (apa yang dilakukan saat diklik/disentuh)
```

### Tools yang Diperlukan

**1. Visual Studio Code (VS Code)**
Editor kode gratis dan populer dari Microsoft. Download di: [https://code.visualstudio.com](https://code.visualstudio.com)

Ekstensi yang direkomendasikan (install dari Marketplace VS Code):
- **Live Server** — melihat perubahan HTML secara langsung tanpa refresh manual
- **Prettier** — memformat kode otomatis agar rapi
- **Auto Rename Tag** — mengubah tag pembuka/penutup HTML secara bersamaan

**2. Browser Modern**
Gunakan Google Chrome atau Mozilla Firefox. Keduanya memiliki Developer Tools (tekan `F12`) yang berguna untuk debugging.

**3. Struktur Folder Project**

Sejak awal, biasakan membuat struktur folder yang rapi:

```
web-portfolio/
├── index.html
├── style.css
├── script.js
└── images/
```

> 💡 **Tips Best Practice:**
> - Gunakan huruf kecil untuk nama file (`index.html`, bukan `Index.HTML`)
> - Gunakan tanda hubung untuk spasi (`about-me.html`, bukan `about me.html`)
> - Jangan gunakan karakter khusus atau spasi di nama file

## 💻 Contoh Kode

### Template HTML Dasar

```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Halaman Pertamaku</title>
</head>
<body>
    <h1>Halo, Dunia!</h1>
    <p>Ini adalah halaman web pertama saya.</p>
</body>
</html>
```

Penjelasan setiap bagian:

| Bagian | Fungsi |
|---|---|
| `<!DOCTYPE html>` | Memberitahu browser ini adalah dokumen HTML5 |
| `<html lang="id">` | Tag akar dokumen, `lang="id"` menandai bahasa Indonesia |
| `<head>` | Berisi metadata (tidak terlihat di halaman) |
| `<meta charset="UTF-8">` | Mendukung karakter Indonesia (ä, é, dll) |
| `<meta name="viewport" ...>` | Agar tampilan responsif di perangkat mobile |
| `<title>` | Judul tab browser |
| `<body>` | Semua konten yang terlihat di halaman |

## 🧪 Praktik: Membuat index.html Pertama

### Langkah 1 — Buat Folder Project

Buat folder baru bernama `web-portfolio` di lokasi yang mudah diakses (misalnya Desktop atau Dokumen).

### Langkah 2 — Buka dengan VS Code

Buka VS Code, lalu pilih **File → Open Folder** dan arahkan ke folder `web-portfolio`.

### Langkah 3 — Buat File index.html

Klik ikon **New File** di panel kiri VS Code, beri nama `index.html`.

### Langkah 4 — Ketik Kode Berikut

```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Portofolio Saya</title>
</head>
<body>
    <h1>Selamat Datang di Portofolio Saya</h1>
    <p>Nama saya <strong>Budi Santoso</strong>. Saya sedang belajar web development.</p>
    <p>Website ini dibuat menggunakan HTML, CSS, dan JavaScript.</p>
</body>
</html>
```

### Langkah 5 — Jalankan dengan Live Server

Klik kanan pada file `index.html` → pilih **Open with Live Server**. Browser akan otomatis membuka halaman.

> Jika belum install Live Server, klik dua kali file `index.html` untuk membukanya langsung di browser.

### Langkah 6 — Eksplorasi Developer Tools

Tekan `F12` di browser untuk membuka Developer Tools. Pergi ke tab **Elements** untuk melihat struktur HTML halaman. Coba ubah teks langsung di sana dan lihat perubahannya secara real-time (perubahan tidak tersimpan, hanya preview).

## 📌 Ringkasan

- Website adalah kumpulan halaman yang diakses melalui browser via internet
- Proses kerja web menggunakan model **request–response** antara browser dan server
- **Frontend** = tampilan yang dilihat pengguna; **Backend** = logika di server
- **HTML** = struktur, **CSS** = tampilan, **JavaScript** = interaktivitas
- Tools utama: **VS Code** (editor) + **Browser** (untuk melihat hasil)
- Struktur folder yang rapi adalah kebiasaan profesional yang harus diterapkan sejak awal
