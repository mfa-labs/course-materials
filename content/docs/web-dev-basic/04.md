# BAB 4: Layouting dengan Flexbox

---

## 🎯 Tujuan Pembelajaran

Setelah menyelesaikan bab ini, peserta diharapkan mampu:

- Memahami konsep Flexbox dan kapan menggunakannya
- Menggunakan properti `display: flex` pada container
- Mengatur alignment dengan `justify-content` dan `align-items`
- Memahami perbedaan arah `row` dan `column`
- Membuat layout navbar dan section menggunakan Flexbox

---

## 📖 Materi

### Mengapa Perlu Flexbox?

Sebelum ada Flexbox, membuat layout di CSS cukup rumit — kita harus menggunakan float, clear, dan berbagai hack yang tidak intuitif. Flexbox hadir sebagai solusi modern untuk **mengatur tata letak (layout) elemen secara fleksibel**.

Analogi: bayangkan kamu punya rak buku (container) dan beberapa buku (item). Flexbox adalah sistem yang mengatur bagaimana buku-buku itu disusun: horizontal atau vertikal, rapat di kiri, tengah, atau tersebar merata.

---

### Konsep Dasar Flexbox

Flexbox bekerja dengan dua komponen:

1. **Flex Container** — elemen induk yang diberi `display: flex`
2. **Flex Items** — elemen anak langsung dari flex container

```html
<!-- Flex Container -->
<div class="container">
    <!-- Flex Items -->
    <div class="item">Item 1</div>
    <div class="item">Item 2</div>
    <div class="item">Item 3</div>
</div>
```

```css
.container {
    display: flex; /* Ini yang mengaktifkan Flexbox */
}
```

---

### Flex Direction (Arah)

Properti `flex-direction` menentukan arah utama (main axis) penempatan item.

```css
.container {
    display: flex;
    flex-direction: row;            /* default: kiri ke kanan → */
    flex-direction: row-reverse;    /* kanan ke kiri ← */
    flex-direction: column;         /* atas ke bawah ↓ */
    flex-direction: column-reverse; /* bawah ke atas ↑ */
}
```

Visualisasi `flex-direction: row` vs `column`:

```
ROW (default):
┌─────────────────────────┐
│ [Item 1] [Item 2] [Item 3] │
└─────────────────────────┘

COLUMN:
┌───────────┐
│  [Item 1] │
│  [Item 2] │
│  [Item 3] │
└───────────┘
```

---

### justify-content (Alignment di Main Axis)

Mengatur distribusi item di sepanjang **main axis** (arah utama).

```css
.container {
    display: flex;

    justify-content: flex-start;    /* item di awal (default) */
    justify-content: flex-end;      /* item di akhir */
    justify-content: center;        /* item di tengah */
    justify-content: space-between; /* item tersebar, tanpa ruang di tepi */
    justify-content: space-around;  /* item tersebar, dengan setengah ruang di tepi */
    justify-content: space-evenly;  /* item tersebar, ruang sama rata termasuk tepi */
}
```

Visualisasi dengan `flex-direction: row`:

```
flex-start:    [A]  [B]  [C]
flex-end:                [A]  [B]  [C]
center:           [A]  [B]  [C]
space-between: [A]     [B]     [C]
space-evenly:    [A]   [B]   [C]
```

---

### align-items (Alignment di Cross Axis)

Mengatur penempatan item di sepanjang **cross axis** (sumbu tegak lurus main axis).

```css
.container {
    display: flex;
    height: 200px;

    align-items: stretch;       /* item mengisi penuh tinggi container (default) */
    align-items: flex-start;    /* item di atas */
    align-items: flex-end;      /* item di bawah */
    align-items: center;        /* item di tengah vertikal */
    align-items: baseline;      /* item sejajar pada baseline teks */
}
```

---

### Kombinasi justify-content dan align-items

Untuk **memusatkan elemen secara sempurna** (horizontal dan vertikal), gunakan kombinasi ini:

```css
.container {
    display: flex;
    justify-content: center;  /* horizontal */
    align-items: center;      /* vertikal */
    height: 300px;
}
```

Ini adalah salah satu hal yang paling sering dicari oleh developer: "how to center a div" — dan Flexbox menyelesaikannya dengan mudah!

---

### Properti pada Flex Items

```css
.item {
    /* flex-grow: seberapa banyak item ini mengambil ruang sisa */
    flex-grow: 1;   /* ambil semua ruang sisa */
    flex-grow: 0;   /* tidak bertumbuh (default) */

    /* flex-shrink: seberapa item ini menyusut jika ruang kurang */
    flex-shrink: 1; /* menyusut jika perlu (default) */
    flex-shrink: 0; /* tidak menyusut */

    /* flex-basis: ukuran dasar item */
    flex-basis: 200px;
    flex-basis: auto;   /* gunakan width/height (default) */

    /* Shorthand: flex: grow shrink basis */
    flex: 1;        /* flex: 1 1 0 — item tumbuh dan menyusut secara merata */
    flex: 0 0 200px; /* ukuran tetap 200px */

    /* order: mengubah urutan tampilan (tanpa mengubah HTML) */
    order: -1;  /* muncul pertama */
    order: 0;   /* urutan default */
    order: 1;   /* muncul terakhir */

    /* align-self: override align-items untuk satu item */
    align-self: center;
    align-self: flex-end;
}
```

---

### flex-wrap (Pembalikan Baris)

Secara default, semua flex item masuk dalam satu baris. Gunakan `flex-wrap` agar item bisa pindah ke baris baru jika ruang tidak cukup.

```css
.container {
    display: flex;
    flex-wrap: nowrap;    /* semua dalam satu baris (default) */
    flex-wrap: wrap;      /* item pindah baris jika perlu */
    flex-wrap: wrap-reverse; /* wrap, tapi dari bawah ke atas */
}
```

## 🧪 Praktik: Layout Navbar & Section

### Langkah 1 — Update index.html

Tambahkan class `navbar`, `hero`, dan `card-grid` sesuai contoh di atas ke file `index.html` kamu.

### Langkah 2 — Update style.css

Tambahkan CSS Flexbox dari contoh di atas ke file `style.css`.

### Langkah 3 — Uji Coba Properti

Eksperimen dengan mengubah nilai-nilai berikut dan amati perubahannya:

```css
/* Coba ubah nilai justify-content */
.navbar {
    justify-content: center;       /* apa yang terjadi? */
    justify-content: flex-start;   /* apa yang terjadi? */
}

/* Coba ubah flex-direction pada card */
.card {
    flex-direction: row;           /* konten tersusun horizontal */
}

/* Coba ubah flex-wrap */
.card-grid {
    flex-wrap: nowrap;             /* semua card dalam satu baris */
}
```

### Langkah 4 — Buat Versi Layout Dua Kolom

Coba buat layout "About" dengan dua kolom (foto di kiri, teks di kanan):

```html
<section class="tentang-section">
    <div class="tentang-container">
        <div class="tentang-foto">
```


## 📌 Ringkasan

- **Flexbox** adalah sistem layout satu dimensi (baris ATAU kolom)
- `display: flex` pada parent mengaktifkan Flexbox untuk child langsung-nya
- `flex-direction` mengatur arah (row/column)
- `justify-content` mengatur distribusi di **main axis** (searah flex-direction)
- `align-items` mengatur distribusi di **cross axis** (tegak lurus flex-direction)
- `flex-wrap: wrap` memungkinkan item pindah baris — penting untuk responsivitas
- `flex: 1` pada item berarti "ambil ruang yang tersedia secara merata"
