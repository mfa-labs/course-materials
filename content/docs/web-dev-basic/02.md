## 📖 Materi

### Struktur Dasar HTML

Setiap dokumen HTML memiliki struktur hierarki seperti pohon. Elemen-elemen bersarang satu sama lain membentuk **DOM (Document Object Model)**.

```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Judul Halaman</title>
</head>
<body>
    <!-- Konten halaman di sini -->
</body>
</html>
```

Konsep penting:
- **Tag** ditulis di dalam tanda `< >`, contoh: `<p>`
- **Tag pembuka** dan **tag penutup** membungkus konten: `<p>teks</p>`
- **Atribut** memberikan informasi tambahan pada tag: `<a href="url">teks</a>`
- **Komentar** tidak ditampilkan di browser: `<!-- ini komentar -->`

---

### Heading dan Paragraf

HTML memiliki 6 level heading (judul), dari yang paling besar (`<h1>`) hingga terkecil (`<h6>`).

```html
<h1>Judul Utama (Hanya satu per halaman)</h1>
<h2>Subjudul</h2>
<h3>Sub-subjudul</h3>
<h4>Level 4</h4>
<h5>Level 5</h5>
<h6>Level 6 (Terkecil)</h6>

<p>Ini adalah sebuah paragraf. Paragraf otomatis memiliki jarak atas dan bawah.</p>
<p>Ini paragraf kedua. Setiap tag <code>&lt;p&gt;</code> membuat paragraf baru.</p>
```

> 💡 **Tips:** Gunakan `<h1>` hanya sekali per halaman untuk keperluan SEO (mesin pencari). Gunakan `<h2>` dan `<h3>` untuk bagian-bagian lainnya.

---

### Pemformatan Teks

```html
<p>Teks ini <strong>sangat penting</strong> (bold dengan makna semantik).</p>
<p>Teks ini <em>ditekankan</em> (italic dengan makna semantik).</p>
<p>Teks ini <b>tebal</b> (bold tanpa makna semantik).</p>
<p>Teks ini <i>miring</i> (italic tanpa makna semantik).</p>
<p>Teks ini <u>bergaris bawah</u>.</p>
<p>Ini kode: <code>console.log("Hello")</code></p>
<p>H<sub>2</sub>O adalah rumus air. (subscript)</p>
<p>E=mc<sup>2</sup> adalah rumus Einstein. (superscript)</p>
<hr> <!-- Garis horizontal pembatas -->
<br> <!-- Pindah baris (line break) -->
```

### Link (Hyperlink)

Link dibuat menggunakan tag `<a>` dengan atribut `href`:

```html
<!-- Link ke halaman lain -->
<a href="https://www.google.com">Pergi ke Google</a>

<!-- Link ke halaman lokal -->
<a href="about.html">Tentang Saya</a>

<!-- Link yang membuka di tab baru -->
<a href="https://www.github.com" target="_blank" rel="noopener noreferrer">GitHub</a>

<!-- Link ke bagian di halaman yang sama (anchor) -->
<a href="#kontak">Hubungi Saya</a>

<!-- Link ke email -->
<a href="mailto:email@contoh.com">Kirim Email</a>
```

> 💡 **Tips:** Selalu tambahkan `rel="noopener noreferrer"` saat menggunakan `target="_blank"` untuk alasan keamanan.

---

### Gambar

Tag `<img>` digunakan untuk menampilkan gambar. Tag ini tidak memiliki tag penutup (self-closing).

```html
<!-- Gambar dari folder images/ -->
<img src="images/foto-profil.jpg" alt="Foto profil saya" width="200" height="200">

<!-- Gambar dari internet -->
<img src="https://via.placeholder.com/300x200" alt="Gambar placeholder">
```

Atribut penting:
- `src` — path atau URL gambar (wajib)
- `alt` — teks alternatif jika gambar gagal dimuat, penting untuk aksesibilitas (wajib)
- `width` dan `height` — dimensi gambar (opsional, lebih baik diatur via CSS)

### List (Daftar)

HTML mendukung tiga jenis list:

```html
<!-- Unordered List (tidak berurutan, menggunakan bullet) -->
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

<!-- Ordered List (berurutan, menggunakan angka) -->
<ol>
    <li>Pelajari HTML</li>
    <li>Pelajari CSS</li>
    <li>Pelajari JavaScript</li>
</ol>

<!-- Nested List (list di dalam list) -->
<ul>
    <li>Frontend
        <ul>
            <li>HTML</li>
            <li>CSS</li>
        </ul>
    </li>
    <li>Backend
        <ul>
            <li>Node.js</li>
            <li>Python</li>
        </ul>
    </li>
</ul>

<!-- Description List (daftar istilah) -->
<dl>
    <dt>HTML</dt>
    <dd>Bahasa markup untuk struktur halaman web</dd>
    <dt>CSS</dt>
    <dd>Bahasa untuk styling halaman web</dd>
</dl>
```

### Semantic HTML

**Semantic HTML** berarti menggunakan tag yang punya makna/arti, bukan hanya untuk tampilan. Ini penting untuk:
- Keterbacaan kode (developer lain mudah memahami)
- Aksesibilitas (screen reader untuk penyandang disabilitas)
- SEO (mesin pencari lebih memahami struktur halaman)

Bandingkan dua pendekatan ini:

```html
<!-- ❌ Tidak Semantik (sulit dibaca, kurang bermakna) -->
<div id="header">...</div>
<div id="nav">...</div>
<div id="main">...</div>
<div id="footer">...</div>

<!-- ✅ Semantik (jelas maknanya) -->
<header>...</header>
<nav>...</nav>
<main>...</main>
<footer>...</footer>
```

Tag semantic yang umum digunakan:

| Tag | Fungsi |
|---|---|
| `<header>` | Bagian kepala halaman atau section |
| `<nav>` | Navigasi/menu |
| `<main>` | Konten utama halaman |
| `<section>` | Bagian/seksi dalam halaman |
| `<article>` | Konten mandiri (posting blog, berita) |
| `<aside>` | Konten sampingan (sidebar) |
| `<footer>` | Bagian bawah halaman atau section |
| `<figure>` | Konten media (gambar dengan caption) |
| `<figcaption>` | Caption untuk `<figure>` |

## 📌 Ringkasan

- HTML memiliki struktur hierarki: `<!DOCTYPE html>` → `<html>` → `<head>` + `<body>`
- Gunakan heading `<h1>`–`<h6>` secara berurutan dan hierarkis
- Tag `<a href="">` untuk link, `<img src="" alt="">` untuk gambar
- List ada tiga jenis: `<ul>` (bullet), `<ol>` (angka), `<dl>` (istilah)
- Semantic HTML menggunakan tag bermakna seperti `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`
- Selalu isi atribut `alt` pada gambar untuk aksesibilitas
