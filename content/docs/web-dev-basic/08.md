# BAB 8: Deployment – Publish Portofolio ke Internet

---

## 📖 Materi

### Apa Itu Deployment?

**Deployment** adalah proses menerbitkan website dari komputer lokal ke server yang bisa diakses oleh siapa saja di internet. Setelah deploy, siapapun bisa membuka website kamu hanya dengan mengetikkan URL-nya.

Analogi: selama ini kamu memasak di dapur sendiri (localhost). Deployment adalah seperti membuka restoran — semua orang bisa datang dan menikmati masakanmu.

---

### Mengapa GitHub Pages?

Ada banyak layanan hosting, tapi **GitHub Pages** adalah pilihan terbaik untuk website statis karena:

- ✅ **Gratis** sepenuhnya
- ✅ **Mudah** disetup, terintegrasi dengan GitHub
- ✅ **Handal** — menggunakan infrastruktur GitHub/Microsoft
- ✅ **HTTPS otomatis** — website aman dengan SSL gratis
- ✅ **Custom domain** — bisa menggunakan domain sendiri (opsional)
- ✅ URL yang profesional: `username.github.io/nama-repo`

---

### Mengenal Git Dasar

**Git** adalah sistem version control — alat untuk melacak perubahan pada kode. Bayangkan seperti "save game" yang bisa kamu kembali kapan saja.

Konsep dasar Git:

| Istilah | Penjelasan |
|---|---|
| **Repository (repo)** | Folder project yang dipantau Git |
| **Commit** | Snapshot perubahan yang disimpan |
| **Branch** | Cabang pengembangan terpisah |
| **Push** | Mengirim perubahan ke GitHub |
| **Pull** | Mengambil perubahan dari GitHub |

Perintah Git yang dibutuhkan:

```bash
git init                      # Inisialisasi repo Git baru
git add .                     # Tambahkan semua file ke staging
git commit -m "Pesan commit"  # Simpan snapshot perubahan
git remote add origin URL     # Hubungkan ke repo GitHub
git push -u origin main       # Kirim ke GitHub
```

## 🧪 Praktik: Deploy Step-by-Step

### Langkah 1 — Install Git

Download dan install Git dari [https://git-scm.com](https://git-scm.com).

Verifikasi instalasi dengan membuka terminal/command prompt dan ketik:

```bash
git --version
```

Jika muncul nomor versi (misal `git version 2.43.0`), Git berhasil diinstall.

---

### Langkah 2 — Konfigurasi Git (Hanya Sekali)

```bash
git config --global user.name "Nama Kamu"
git config --global user.email "email@kamu.com"
```

Ganti dengan nama dan email yang sama dengan akun GitHub kamu.

---

### Langkah 3 — Buat Akun GitHub

1. Pergi ke [https://github.com](https://github.com)
2. Klik **Sign Up** dan isi form pendaftaran
3. Verifikasi email
4. Pilih username yang profesional — ini akan menjadi bagian dari URL portofolio kamu (contoh: `budisantoso`)

---

### Langkah 4 — Buat Repositori Baru di GitHub

1. Login ke GitHub
2. Klik tombol **+** di pojok kanan atas → pilih **New repository**
3. Isi pengaturan repositori:
   - **Repository name:** `web-portfolio` (atau nama lain)
   - **Description:** `Website portofolio saya` (opsional)
   - **Visibility:** Public ✅ (harus public untuk GitHub Pages gratis)
   - **Jangan centang** "Add a README file" (kita sudah punya file sendiri)
4. Klik **Create repository**

---

### Langkah 5 — Siapkan Project Lokal

Buka terminal/command prompt, lalu navigasi ke folder project:

```bash
# Navigasi ke folder project
cd Desktop/web-portfolio

# Pastikan file-file ada
ls
# Hasilnya harus menampilkan: index.html  style.css  script.js  images/
```

---

### Langkah 6 — Inisialisasi Git & Commit Pertama

```bash
# Inisialisasi Git di folder project
git init

# Tambahkan semua file ke staging area
git add .

# Buat commit pertama
git commit -m "Initial commit: portofolio web pertama saya"
```

Jika berhasil, akan muncul pesan seperti:

```
[main (root-commit) a1b2c3d] Initial commit: portofolio web pertama saya
 4 files changed, 200 insertions(+)
 create mode 100644 index.html
 create mode 100644 style.css
 create mode 100644 script.js
```

---

### Langkah 7 — Hubungkan ke GitHub & Push

Salin URL repository dari halaman GitHub kamu. Biasanya berbentuk:
`https://github.com/username/web-portfolio.git`

```bash
# Hubungkan local repo ke GitHub
git remote add origin https://github.com/USERNAME/web-portfolio.git

# Ganti nama branch utama menjadi "main" (standar terbaru)
git branch -M main

# Kirim (push) ke GitHub
git push -u origin main
```

Kamu akan diminta username dan password/token GitHub. Ikuti petunjuknya.

> 💡 **Catatan:** GitHub tidak lagi menerima password biasa. Gunakan **Personal Access Token (PAT)**. Cara membuatnya: GitHub → Settings → Developer Settings → Personal Access Tokens → Generate new token. Centang scope `repo`.

---

### Langkah 8 — Aktifkan GitHub Pages

1. Pergi ke repositori kamu di GitHub
2. Klik tab **Settings**
3. Di menu kiri, klik **Pages**
4. Di bagian **Source**, pilih:
   - Branch: **main**
   - Folder: **/ (root)**
5. Klik **Save**

GitHub akan menampilkan pesan:

```
Your site is live at https://username.github.io/web-portfolio/
```

> ⏳ Tunggu 1–3 menit untuk proses deployment pertama. Refresh halaman untuk melihat status terbaru.

---

### Langkah 9 — Buka Website Kamu!

Ketikkan URL di browser:

```
https://username.github.io/web-portfolio/
```

Ganti `username` dengan username GitHub kamu dan `web-portfolio` dengan nama repositori.

🎉 **Selamat! Website portofolio kamu sudah online!**

---

### Langkah 10 — Update Website Setelah Perubahan

Setiap kali membuat perubahan pada kode, lakukan langkah ini untuk mempublikasikan update:

```bash
# Tambahkan semua perubahan
git add .

# Commit dengan pesan yang deskriptif
git commit -m "Tambah section baru: pengalaman kerja"

# Push ke GitHub
git push
```

GitHub Pages akan otomatis memperbarui website dalam 1–2 menit.

---

## 💻 Referensi Cepat: Perintah Git

```bash
# Melihat status file (berubah, ditambahkan, dll)
git status

# Melihat riwayat commit
git log --oneline

# Melihat perubahan yang belum di-commit
git diff

# Menambahkan file tertentu saja
git add index.html

# Membatalkan perubahan pada file (hati-hati!)
git checkout -- nama-file.html

# Menarik perubahan terbaru dari GitHub
git pull
```

## ✅ Tips Mempublikasikan Portofolio

### Pastikan Sebelum Deploy:

```
[ ] Semua link berfungsi (cek dengan klik satu per satu)
[ ] Semua gambar tampil dengan benar
[ ] Tidak ada teks placeholder yang tersisa ([Nama Kamu], [email], dll)
[ ] Website responsif di mobile
[ ] Tidak ada error di Console DevTools (F12)
[ ] Judul tab (<title>) sudah sesuai namamu
[ ] Meta description sudah diisi
```

### Best Practice Setelah Deploy:

**1. Gunakan URL yang mudah diingat**

Pertimbangkan untuk membeli domain kustom (contoh: `budisantoso.com`). Harganya sekitar Rp 100.000–200.000/tahun. GitHub Pages mendukung custom domain secara gratis.

**2. Optimalkan untuk Mesin Pencari (SEO)**

```html
<!-- Tambahkan di <head> -->
<meta name="description" content="Portofolio web developer Budi Santoso dari Medan. Spesialisasi HTML, CSS, JavaScript.">
<meta name="keywords" content="web developer, portofolio, Medan, HTML, CSS, JavaScript">
<meta name="author" content="Budi Santoso">

<!-- Open Graph untuk tampilan di media sosial -->
<meta property="og:title" content="Budi Santoso | Web Developer">
<meta property="og:description" content="Web developer dari Medan yang bersemangat">
<meta property="og:image" content="https://username.github.io/web-portfolio/images/profil.jpg">
<meta property="og:url" content="https://username.github.io/web-portfolio">
<meta property="og:type" content="website">
```

**3. Tambahkan file robots.txt**

Buat file `robots.txt` di root folder:

```
User-agent: *
Allow: /

Sitemap: https://username.github.io/web-portfolio/sitemap.xml
```

**4. Perbarui secara berkala**

Portofolio yang tidak pernah diperbarui terlihat tidak aktif. Tambahkan proyek baru minimal setiap 1–2 bulan.

**5. Bagikan URL portofolio**

- Tambahkan di profil LinkedIn
- Cantumkan di CV/resume
- Sertakan di email signature
- Bagikan di komunitas developer

## 🌐 Alternatif Platform Hosting

Selain GitHub Pages, ada beberapa alternatif gratis yang populer:

| Platform | URL | Kelebihan |
|---|---|---|
| **GitHub Pages** | username.github.io/repo | Terintegrasi dengan GitHub, mudah update |
| **Netlify** | nama.netlify.app | Deploy drag & drop, form handling gratis |
| **Vercel** | nama.vercel.app | Performa tinggi, auto-deploy dari GitHub |
| **Cloudflare Pages** | nama.pages.dev | CDN global, performa sangat cepat |

Semua platform di atas gratis untuk website statis. Pilih sesuai kebutuhan.

## 📌 Ringkasan

- **Deployment** adalah proses menerbitkan website agar bisa diakses publik via internet
- **GitHub Pages** adalah layanan hosting gratis untuk website statis dari GitHub
- **Git** adalah sistem version control untuk melacak perubahan kode
- Workflow dasar: `git add .` → `git commit -m "pesan"` → `git push`
- Aktifkan GitHub Pages dari **Settings → Pages → Source: main branch**
- URL website akan berbentuk: `https://username.github.io/nama-repo/`
- Setiap update kode cukup dengan `git add .`, `git commit`, lalu `git push`
