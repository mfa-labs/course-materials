## 📖 Materi

### Apa Itu CSS?

CSS adalah bahasa yang digunakan untuk **mengatur tampilan** elemen HTML. Jika HTML adalah rangka rumah, CSS adalah cat, wallpaper, lampu, dan dekorasi yang membuatnya indah.

Sintaks dasar CSS:

```css
selector {
    properti: nilai;
    properti-lain: nilai-lain;
}
```

Contoh:

```css
h1 {
    color: blue;
    font-size: 32px;
}
```

Artinya: "Semua elemen `<h1>` akan berwarna biru dengan ukuran font 32px."

---

### Cara Menggunakan CSS

Ada tiga cara menambahkan CSS ke halaman HTML:

#### 1. Inline CSS (Langsung di Elemen)

```html
<p style="color: red; font-size: 18px;">Teks ini berwarna merah.</p>
```

✅ Kelebihan: Cepat untuk testing  
❌ Kekurangan: Sulit dikelola, tidak bisa digunakan ulang, mengotori HTML

#### 2. Internal CSS (Di dalam Tag `<style>`)

```html
<head>
    <style>
        p {
            color: blue;
            font-size: 16px;
        }
    </style>
</head>
```

✅ Kelebihan: Tidak perlu file terpisah  
❌ Kekurangan: Hanya berlaku untuk satu halaman

#### 3. External CSS (File Terpisah) ✅ DIREKOMENDASIKAN

```html
<!-- Di dalam file HTML -->
<head>
    <link rel="stylesheet" href="style.css">
</head>
```

```css
/* Di dalam file style.css */
p {
    color: darkblue;
    font-size: 16px;
}
```

✅ Kelebihan: Satu file CSS bisa dipakai banyak halaman, kode lebih rapi  
❌ Kekurangan: Perlu file tambahan

> 💡 **Best Practice:** Selalu gunakan **External CSS** untuk project nyata.

### Selector CSS

Selector menentukan **elemen mana** yang akan diberi gaya.

```css
/* Selector elemen (semua tag p) */
p {
    color: gray;
}

/* Selector class (elemen dengan class="kotak") */
.kotak {
    background-color: lightblue;
    padding: 10px;
}

/* Selector ID (elemen dengan id="judul-utama") */
#judul-utama {
    font-size: 36px;
    color: darkblue;
}

/* Selector gabungan (semua <p> di dalam <section>) */
section p {
    line-height: 1.6;
}

/* Selector pseudo-class (link saat dihover) */
a:hover {
    color: orange;
    text-decoration: underline;
}

/* Selector pseudo-class (elemen pertama dari jenisnya) */
li:first-child {
    font-weight: bold;
}
```

Perbedaan Class vs ID:

| | Class | ID |
|---|---|---|
| Simbol di CSS | `.` (titik) | `#` (tagar) |
| Di HTML | `class="nama"` | `id="nama"` |
| Bisa dipakai | Banyak elemen | Hanya satu elemen per halaman |

### Font dan Tipografi

```css
body {
    font-family: 'Arial', sans-serif;   /* Font dan fallback */
    font-size: 16px;                    /* Ukuran font */
    font-weight: normal;                /* normal, bold, 100–900 */
    font-style: italic;                 /* normal, italic, oblique */
    line-height: 1.6;                   /* Jarak antar baris */
    letter-spacing: 0.5px;             /* Jarak antar huruf */
    text-align: center;                 /* left, right, center, justify */
    text-decoration: none;              /* none, underline, line-through */
    text-transform: uppercase;          /* uppercase, lowercase, capitalize */
}
```

```html

```

```css
/* Kemudian gunakan di CSS */
```

### Margin dan Padding

Ini adalah salah satu konsep yang paling sering membingungkan pemula. Pahami perbedaannya:

- **Margin** = Ruang di **luar** elemen (antara elemen ini dan elemen lain)
- **Padding** = Ruang di **dalam** elemen (antara konten dan tepi elemen)

```css
.kotak {
    /* Semua sisi sama */
    margin: 20px;
    padding: 10px;

    /* Atas-Kanan-Bawah-Kiri (searah jarum jam) */
    margin: 10px 20px 10px 20px;

    /* Atas-Bawah dan Kiri-Kanan */
    margin: 10px 20px;

    /* Masing-masing sisi */
    margin-top: 10px;
    margin-right: 20px;
    margin-bottom: 10px;
    margin-left: 20px;

    /* Auto (sering digunakan untuk horizontally center) */
    margin: 0 auto;
}
```

### Box Model

Setiap elemen HTML adalah sebuah "kotak" yang terdiri dari 4 lapisan:

```
┌──────────────────────────────────────┐
│              MARGIN                  │
│   ┌──────────────────────────────┐   │
│   │           BORDER             │   │
│   │   ┌──────────────────────┐   │   │
│   │   │       PADDING        │   │   │
│   │   │   ┌──────────────┐   │   │   │
│   │   │   │   CONTENT    │   │   │   │
│   │   │   └──────────────┘   │   │   │
│   │   └──────────────────────┘   │   │
│   └──────────────────────────────┘   │
└──────────────────────────────────────┘
```

```css
.kotak {
    width: 300px;               /* Lebar konten */
    height: 150px;              /* Tinggi konten */
    padding: 20px;              /* Ruang dalam */
    border: 2px solid black;   /* Garis tepi */
    margin: 15px;               /* Ruang luar */

    /* Penting: box-sizing: border-box membuat width mencakup padding dan border */
    box-sizing: border-box;
}
```

> 💡 **Selalu gunakan `box-sizing: border-box`!** Tambahkan ini di awal CSS kamu:
> ```css
> * {
>     box-sizing: border-box;
> }
> ```
> Ini membuat kalkulasi ukuran elemen jauh lebih mudah dan intuitif.

### Properti CSS Lainnya yang Sering Dipakai

```css
.elemen {
    /* Background */
    background-color: #f5f5f5;
    background-image: url('images/bg.jpg');
    background-size: cover;         /* cover, contain, atau ukuran */
    background-position: center;

    /* Border */
    border: 1px solid #ccc;
    border-radius: 8px;             /* sudut membulat */
    border-radius: 50%;             /* lingkaran penuh */

    /* Shadow */
    box-shadow: 0px 4px 10px rgba(0, 0, 0, 0.1);
    text-shadow: 1px 1px 3px rgba(0, 0, 0, 0.3);

    /* Display */
    display: block;
    display: inline;
    display: inline-block;
    display: none;                  /* menyembunyikan elemen */

    /* Opacity dan Visibility */
    opacity: 0.8;                   /* 0 = transparan, 1 = penuh */
    visibility: hidden;             /* tersembunyi tapi tetap memakan ruang */

    /* Cursor */
    cursor: pointer;                /* tampilkan cursor tangan */

    /* Overflow */
    overflow: hidden;               /* sembunyikan konten yang meluap */
    overflow: scroll;               /* tampilkan scrollbar */
}
```

## 🧪 Praktik: Styling Halaman HTML

### Langkah 1 — Buat File style.css

Di folder `web-portfolio`, buat file baru bernama `style.css`.

### Langkah 2 — Hubungkan CSS ke HTML

Pastikan tag berikut ada di dalam `<head>` pada `index.html`:

```html
<link rel="stylesheet" href="style.css">
```

### Langkah 3 — Salin CSS di Atas

Salin konten CSS dari contoh kode di atas ke file `style.css`.

### Langkah 4 — Sesuaikan dengan Konten Milikmu

Ganti warna, font, dan ukuran sesuai selera. Eksperimen dengan:

```css
/* Coba ganti nilai-nilai ini */
background-color: #1a1a2e;    /* Coba warna gelap berbeda */
font-family: 'Georgia', serif; /* Coba font berbeda */
border-radius: 15px;           /* Coba sudut lebih membulat */
```

### Langkah 5 — Gunakan Developer Tools untuk Inspeksi

Klik kanan elemen di browser → pilih **Inspect**. Di panel kanan (Styles), kamu bisa mengubah CSS secara langsung untuk melihat efeknya sebelum menulis ke file.

## 📌 Ringkasan

- CSS mengontrol tampilan elemen HTML menggunakan selector, properti, dan nilai
- Ada tiga cara penggunaan CSS: **inline, internal**, dan **external** (external paling direkomendasikan)
- **Selector** menentukan elemen mana yang ditarget; gunakan class (`.`) untuk fleksibilitas
- **Box Model** terdiri dari content → padding → border → margin
- Selalu gunakan `box-sizing: border-box` di reset CSS
- **Margin** = ruang luar elemen; **Padding** = ruang dalam elemen
